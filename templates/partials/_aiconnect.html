Claude

  1. On claude.ai or in the Claude desktop app, open Settings → Customize → Connectors.
  2. Select + Add, then Add custom connector.
  3. Name it The Investor Project, paste the address above as the URL, and select Continue.
  4. Claude fills in the sign-in settings for you (Sign in now and Register automatically, each marked Detected). Leave them and the rest as they are, and select Add.
  5. Claude then says “You're not connected to The Investor Project yet.” Select Connect. In the desktop app, your browser opens and asks “Finish connecting a connector?”: select Continue connecting.
  6. Sign in to The Investor Project if you aren't already. On “Connect Claude to The Investor Project?”, choose See my portfolio (look only) or See my portfolio and trade, and select Allow.
  7. You go back to Claude, which says “Connected to The Investor Project.” In the desktop app, your browser first asks “Open Claude?”: select Open Claude.
  8. Start a new chat and ask “What's in my Investor Project portfolio?” A connector you add on the web works in Claude's phone app too.

Stop Claude asking every time

Claude asks before it uses each tool the first time, such as Get portfolio or Get leaderboard. These prompts are Claude's own check, so The Investor Project can't turn them off for you. To stop them:

  • When Claude asks, choose Always allow. It won't ask about that tool again.
  • Or allow them all at once: in Settings → Customize → Connectors, select The Investor Project. Under Tool permissions, open the menu beside Read-only tools and choose Always allow. You can also set each tool on its own with the tick (always allow), hand (needs approval) and no-entry (never) buttons beside it.

The two Write/delete tools, Place order and Cancel order, are the only ones that change anything. You might leave them on Needs approval, so nothing trades without you seeing it first. Either way, Claude shows you each order before placing it unless you tell it to trade without asking.

ChatGPT

  1. Open Settings → Apps & Connectors → Create. ChatGPT may ask you to turn on developer mode first.
  2. Paste the address above. If it asks how to sign in, choose OAuth.
  3. Sign in to The Investor Project when asked, and choose whether ChatGPT can trade or only look.

Connectors, and how they're named in settings, depend on your plan and change from time to time. Check Claude's or ChatGPT's help if the steps don't match.
